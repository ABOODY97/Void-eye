# أداة VOID EYE
## 🌟 نبذة عن الأداة
أداة **VOID EYE (Mini Wireshark)** هي أداة متقدمة ومبسطة لمراقبة وتحليل حزم الشبكة (Packet Sniffing). تقوم الأداة باعتراض الحزم المارة عبر كرت الشبكة وتحليلها لعرض المصدر والوجهة مع التعرف التلقائي على أسماء المواقع والخدمات المعروفة بفضل نظام الـ Resolver الذكي.

## ✨ المميزات
*   **دعم لغة العربية بلترمنل!** 🇸🇦 (تُعرض النصوص بشكل سليم بفضل `arabic_reshaper` و `python-bidi`).
*   **مراقبة حية للشبكة:** التقاط وتحليل حزم TCP, UDP, و ICMP في الوقت الفعلي.
*   **التعرف الذكي على العناوين:** تحويل عناوين IP إلى أسماء مواقع مفهومة باستخدام قاعدة بيانات مدمجة وذاكرة تخزين مؤقت (Cache).
*   **تحديد كرت الشبكة:** واجهة تفاعلية لاختيار الواجهة الشبكية (Interface) بسهولة.

## ⚠️ إخلاء المسؤولية
> **تنويه:** هذه الأداة قابلة للتطوير بشكل ملحوظ بسبب بساطتها. تم تصميمها للأغراض التعليمية واختبار الشبكات فقط. يُرجى استخدامها ضمن الصلاحيات القانونية والأخلاقية.

## 🛠️ المتطلبات والتثبيت

1. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

2. تشغيل الأداة (تحتاج إلى صلاحيات Root/Administrator):
```bash
sudo python3 void_eye.py
```
